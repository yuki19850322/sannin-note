退職の伝え方、AIで準備する。

「辞めます」の一言が出ない。引き止められたら押し切られそう。言う順番と言葉をAIで先に作っておくと、当日は読むだけになります。自分で言うのがどうしても無理なときの手段も最後にまとめました。

ANSWER FIRST

まず直属の上司に、口頭で「退職したい」と伝えます。日にちは就業規則の「退職の申し出の期限」（1か月前などが多い）に合わせると、話がこじれにくくなります。

言う言葉は、AIで「切り出しの一言」「理由」「引き止められたときの返し」の3つを作っておきます。理由は会社への不満ではなく、「決めたこと」として短く伝えるのがコツです。

ORDER

伝える順番は、この4つ

  1. 就業規則で「何日前までに言うか」を確かめる雇用期間の定めがない働き方なら、法律上は申し出から2週間で退職できます。ただ、引き継ぎや有給休暇の消化を考えると、会社の規則に合わせた方が円満に進みます。
  2. 直属の上司に「お時間をいただけますか」と声をかけるメールやチャットで「ご相談したいことがあります」と時間をもらい、会議室など2人で話せる場所で伝えます。同僚に先に話すのは避けます。
  3. 退職日と最終出社日を決める有給休暇が残っていれば、最終出社日のあとに消化する形が一般的です。決まったことはメールでも送って、文字で残しておきます。
  4. 退職届を出し、引き継ぎ表を作る会社に決まった書式があればそれを使います。引き継ぎは「誰に・何を・いつまでに」を表にしておくと、最後の数週間が楽になります。
PROMPT 1

切り出しの一言と、引き止めへの返し

AIに状況を渡して、当日そのまま読める言葉にしてもらいます。

私は会社を辞めることを決めました。直属の上司に伝える言葉を作ってください。 ・辞める理由（本音）：（例：残業が多く、体がもたない／やりたい仕事が別にある） ・希望の退職日：（例：2か月後の月末） ・残っている有給休暇：（例：12日） 作ってほしいもの： 1. 最初の一言（15秒で言える長さ） 2. 理由の伝え方（会社や人の悪口にしない、「決めたこと」として伝える） 3. 引き止められたときの返し方を3パターン 　（「給料を上げる」「部署を変える」「今は困る、もう少し待って」と言われた場合） 丁寧だけど、相談ではなく報告だと分かる言い方にしてください。

引き止めで条件を出されても、その場で返事をしないのがいちばん大事です。「ありがとうございます。ただ、気持ちは変わりません」とくり返せば十分です。

PROMPT 2

退職届の文面と、引き継ぎ表

会社に書式がない場合の退職届と、引き継ぎ表のたたき台もAIで作れます。

退職届の文面を作ってください。 ・会社名と代表者名：（例：株式会社〇〇 代表取締役 〇〇様） ・自分の所属と名前：（例：営業部 山田花子） ・退職日：（例：2027年1月31日） 理由は「一身上の都合」とし、A4縦書き1枚に収まる形にしてください。 あわせて、引き継ぎ表を作ってください。 私の担当業務は次のとおりです：（ここに業務を箇条書き） 「業務名／頻度／引き継ぐ相手（空欄）／資料の場所／注意点」の列で表にしてください。

「退職願」は会社にお願いして合意してもらう書類、「退職届」は辞めることを届け出る書類です。上司と話して退職日が決まったあとに出すなら、退職届で大丈夫です。

IF YOU CANNOT

どうしても自分で言えないとき

上司が怖くて話せない、言ったけれど「認めない」と言われて進まない、体調を崩して会社に行けない。そんなときは、自分で言うことにこだわらなくて大丈夫です。

  • まず無料で相談するなら：労働局の総合労働相談コーナー（国の窓口）
  • 伝えるのを任せたいなら：退職代行。会社と退職日や有給休暇の話をしたいなら、弁護士か労働組合が運営しているものを選びます
